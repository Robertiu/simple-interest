# Proyecto: Cálculo de Interés Simple

Este repositorio contiene un script en Bash para calcular el interés simple con base en tres valores proporcionados por el usuario: capital, tasa de interés y tiempo.

## ¿Cómo usar?

1. Clona el repositorio
2. Da permisos al script: `chmod +x simple-interest.sh`
3. Ejecuta: `./simple-interest.sh`
