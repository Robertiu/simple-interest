# Código de Conducta

Nos comprometemos a crear un ambiente respetuoso, colaborativo e inclusivo.

Todos los participantes deben:

- Ser respetuosos
- Evitar lenguaje ofensivo
- Colaborar con buena fe

Este proyecto adopta el [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) como su código de conducta.
